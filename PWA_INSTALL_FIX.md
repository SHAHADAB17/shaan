# ShaanChat installable PWA fix

## What was wrong
- The root `index.html` linked to an inline `data:` manifest with no 192×192 or 512×512 icons. That is a common reason Chrome does not offer a proper installable PWA.
- The root service worker only cached a small subset of the app. It is updated to precache the first-party app shell and icons.
- The manifest and icon paths are now relative, so they work at the GitHub Pages site root and are less fragile if the files are served from a subpath.
- The `www/` deployment folder has been kept consistent as an alternative deployment target.

## Publish to GitHub Pages
1. Download and extract this ZIP.
2. Open the extracted folder `shaan-main`.
3. Upload/commit the **contents** of `shaan-main` to the same GitHub repository that publishes `https://shahadab17.github.io/`. Keep the folders `icons/` and `www/` intact.
4. In GitHub, open **Settings → Pages** and confirm the correct branch and folder are selected. If the site publishes from the repository root, use the root `index.html`, `manifest.json`, `service-worker.js`, and `icons/` files. Do not publish both root and `www/` versions as competing roots.
5. Wait for GitHub Pages to deploy. Confirm these URLs open in Chrome without 404:
   - `https://shahadab17.github.io/manifest.json`
   - `https://shahadab17.github.io/service-worker.js`
   - `https://shahadab17.github.io/icons/icon-192.png`
   - `https://shahadab17.github.io/icons/icon-512.png`

## Refresh Chrome's installability check on Android
1. Open the site in Chrome (not an in-app browser or Incognito).
2. Open Chrome → site information / **Settings → Site settings** → **Storage** and clear the site's data if it keeps using the old manifest/service worker. This signs you out locally and may clear local site settings; it does not delete Firebase account data.
3. Reload the site twice and wait a few seconds for the new service worker to install.
4. Open Chrome's ⋮ menu. Look for **Install app** or **Add to Home screen**. Exact wording varies by Chrome version and installability state.

## Important
- GitHub Pages must serve the site over HTTPS; it does for the normal `github.io` domain.
- The APK and PWA are different. This project is an installable web app; no APK is generated by this change.
- Installability does not guarantee offline login, chat, voice/video calls, notifications, or Firebase features will work without network access. Test those separately.
- If you deploy the `www/` directory as the published site instead, use the files inside `www/` consistently. Do not mix its files with the root deployment.
- The project uses Firebase. Check Firestore and Storage security rules before sharing the site publicly.
